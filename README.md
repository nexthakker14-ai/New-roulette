# Btc_5m_100% — Telegram signal bot

Бот аналізує BTC_USDT perpetual futures на MEXC за 5-хвилинними свічками та 71 шаблоном із `patterns.json`. Він **не має API-ключів біржі та не відкриває угоди**.

## Як запустити локально

1. Створи Telegram-бота через [@BotFather](https://t.me/BotFather).
2. Встанови Python 3.12+.
3. Виконай:

```bash
pip install -r requirements.txt
```

4. Задай змінну `BOT_TOKEN` (нікому не показуй токен):

```bash
# Windows PowerShell
$env:BOT_TOKEN="токен_від_BotFather"
python bot.py

# Linux/macOS
export BOT_TOKEN="токен_від_BotFather"
python bot.py
```

5. Відкрий свого Telegram-бота і надішли `/start`. Після цього цей чат збережеться для сповіщень.

Команди: `/start`, `/status`, `/stats`, `/help`.

## Розгортання на GitHub + Railway

1. Створи новий GitHub-репозиторій і завантаж **усі файли та папки** з цього архіву.
2. У Railway створи проєкт: **New Project → Deploy from GitHub Repo** і вибери репозиторій.
3. У сервісі Railway відкрий **Variables** і додай `BOT_TOKEN` зі свого @BotFather.
4. (Рекомендовано) Додай Railway Volume, змонтуй його в `/data`. Це збереже стан бота та статистику після перезапусків.
5. Дочекайся успішного Deploy, відкрий Telegram і надішли боту `/start`.

Railway автоматично використовує `Dockerfile` та `railway.json`. Для цього бота не потрібні MEXC API key/secret — використовуються лише публічні ринкові дані.

## Логіка

- У кожному шаблоні задано 6 позицій; проміжні свічки будь-якого кольору.
- Цикл кожного шаблону незалежний. Після результату наступний цикл починається зі свічки після шести свічок перевірки.
- PRE надсилається, коли формується остання потрібна свічка, якщо попередні п'ять позицій збігаються.
- SIGNAL — тільки після закриття останньої свічки та підтвердження всіх шести позицій.
- Після SIGNAL перевіряються наступні 6 свічок: LONG має WIN, якщо є хоча б одна зелена; SHORT — якщо є хоча б одна червона. LOSS — коли всі шість протилежного кольору.
- Doji не прирівнюється до червоної чи зеленої. Якщо немає свічки у напрямку сигналу, але є doji, результат буде VOID, а не помилковий LOSS.
- Під час першого запуску бот починає нові цикли з наступної 5-хвилинної свічки й не надсилає старі сигнали з історії.

## Важливо

Історичні 100% WIN у CSV — це результат минулого періоду, а не гарантія майбутнього. Спочатку тестуй на демо/без реальних коштів. Ф'ючерси мають високий ризик.
